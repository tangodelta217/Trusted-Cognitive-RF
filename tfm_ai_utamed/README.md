# TFM Inteligencia Artificial - UTAMED

## Percepción RF confiable con SSL, assurance, FL y RL

Este módulo contiene el trabajo del TFM de IA enfocado en:

- Self-supervised learning para representaciones RF
- Assurance (calibración, OOD, open-set)
- Federated learning robusto
- Digital twin + RL para planificación de sensado

## Estructura

```
tfm_ai_utamed/
├── ssl/         # Self-supervised learning
├── assurance/   # Calibración e incertidumbre
├── federated/   # Federated learning robusto
└── rl_twin/     # Digital twin + RL
```

## Contribuciones (A1-A4)

- **A1**: RF foundation model pequeño (SSL) + evaluación downstream
- **A2**: Assurance (ECE + riesgo-cobertura + OOD/open-set)
- **A3**: FL robusto (FedAvg baseline + agregación robusta)
- **A4**: Digital twin + RL (MDP, comparación vs heurísticas)
