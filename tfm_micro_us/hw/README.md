# Hardware - TFM Microelectrónica

Diseño hardware para aceleración en FPGA.

## Contenido futuro

- Código HLS (C/C++) para síntesis

## Opciones de acelerador

1. **Opción preferida**: Núcleo de inferencia cuantizada (INT8/INT4)
2. **Opción alternativa**: Canalizador DSP (FFT/STFT/PFB)
